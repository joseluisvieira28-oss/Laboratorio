# CRYPTO EDGE RADAR V0.2 — Public Shadow Service Scope

Status: SHADOW INFRASTRUCTURE ONLY

This increment extends V0.1 with a bounded/continuous public-data service loop, heartbeat/status persistence, local notification sinks, and real public-data soak validation.

Hard constraints:
- no live trading
- no authenticated exchange APIs
- no API keys or secrets
- no order/account/position/cancel/amend endpoints
- no exchange mutation
- no strategy auto-promotion
- registry remains empty unless a separately governed research promotion explicitly authorizes an adapter
- no merge to main implied
- fail closed on market-data, persistence, or evaluation errors

V0.2 acceptance:
1. public Binance USD-M data can drive repeated observation cycles;
2. each cycle emits a persisted service heartbeat/status record;
3. service health is queryable from a local status file and the evidence chain;
4. notification sink records health transitions and future valid shadow signals without sending orders;
5. bounded soak mode supports CI proof without pretending GitHub Actions is a 24/7 deployment;
6. offline safety tests remain green;
7. public-data soak test is green before V0.2 closeout.
