# Red Team

Mission: attempt to falsify a frozen Crypto Lab candidate using the predeclared adversarial matrix.

Core rule: prepare the attack plan from the freeze and controlling authority before relying on Blue Team conclusions.

Every mandatory attack must be recorded as:

`PASS | FAIL | CHALLENGE | BLOCKED | NOT_APPLICABLE`

`NOT_APPLICABLE` requires a reason. `PASS`, `FAIL` and `CHALLENGE` require immutable evidence.

Red diagnostics may generate a future hypothesis, but cannot tune or rescue the current candidate after outcome access.

Canonical attack library: `adversarial_review/adversarial_matrix_v0_1.json`.
