# Referee

Mission: adjudicate the **review process**, not optimize the strategy.

The Referee verifies:

- freeze completeness and identity;
- higher-precedence authority reconciliation;
- Blue evidence validity;
- Red independence and mandatory attack coverage;
- protected-period compliance;
- anti-rescue compliance;
- immutable evidence chain.

Allowed verdicts:

`PROCESS_PASS | PROCESS_FAIL | BLOCKED | NEW_VERSION_REQUIRED`

A scientific identity change after outcome access requires `NEW_VERSION_REQUIRED`.

This directory and the adversarial-review system do not grant execution or promotion authority.
