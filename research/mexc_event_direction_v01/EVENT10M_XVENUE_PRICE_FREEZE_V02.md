Hypothesis: BTC/ETH Binance USD-M perpetual aggregate trade prices and MEXC Event Futures underlying index prices are comparably observable on a **same local monotonic time grid**. Frozen exact stream endpoints: Binance USD-M combined public websocket btcusdt@aggTrade plus ethusdt@aggTrade; MEXC public sub.index.price BTC_USDT + ETH_USDT; same previous publicly documented origins. Single bounded 180-second window, no retry/substitution/repeating after the result. No auth, paid source, exchange order, account, Telegram send, market manipulation or protected September 2026 holdout. Excludes NVIDIA, MU and SPCX.

Feature as-of law: Each incoming public trade or index tick records same-run monotonic local receive ns, UTC receipt ms, exact provider observed price and raw message hash. Grid origin is the latest of the **four** first valid receipts across (BTC,ETH)x(Binance,MEXC). For t=origin+15s, then every 5s until run completion, compute Binance and MEXC **15-second trailing** log return in basis points, using only LAST RECEIVED price at or before t and t-15s, provided each accepted price is no older than 5s from the relevant grid boundary; otherwise skip that paired bin. NO future return, no t+10min outcome, no price interpolation. 15s returns evaluated at 5s intervals OVERLAP and are not independent trades.
Diagnostics: each symbol's paired bin count, nonzero return coverage, contemporaneous Pearson correlation (descriptive only, not statistical significance), fraction matching contemporaneous signs, number of Binance prior-15sec absolute moves >=5.0bps and whether contemporaneous MEXC trailing-15sec return sign matched. No changes to 5s/15s/5bps following source receipt; no optimize and no predictive inference.

SOURCE gate: >=120sec of both streams overlapping; >=18 paired, fully as-of grid bins and >=10 nonzero returns per source for EACH symbol; no socket errors. If fails, SOURCE_INCOMPLETE. If passes, PRICE_COMPARABILITY_SOURCE_PASS. Both verdicts mean **zero** predictive evidence and **zero** certified edge. Even 100% contemporaneous agreement cannot prove a future 10-minute direction, or matching Event Futures server-assigned entry/expiry, or payout availability and human Telegram reaction.
