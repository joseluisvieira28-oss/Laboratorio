# Event-10M pre-expiry artifact timestamp precision errata
29 October 2026, before first prospective November outcome.
GitHub Actions artifact REST `created_at` is UTC ISO date at *seconds* resolution while the preserved decision is millisecond precision. A genuine artifact uploaded after a decision at XX:YY:SS.600 could have API `created_at=XX:YY:SS.000`; rejecting all `published_ms<decision_ms` is incorrect and contradicts existing V0.7 independent server metadata test allowing up to 999ms timestamp truncation. The V0.6 strict offline mechanic is corrected in this NEW V0.7 research branch to allow published_ms >= decision_ms-1000, STILL requiring: independent GitHub artifact SHA+exact original decision bytes+same-run metadata, an actual GitHub server-created_at **strictly BEFORE target** and <10min interval, no post-outcome modification. All financial thresholds, directional model and minimum counts are unchanged. This never rescues or backdates an actual published artifact. Original PR #283 revision is untouched; independent audit shows no real market outcome evaluated yet.
