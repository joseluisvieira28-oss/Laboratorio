# Next Mine — Source Risk Register

Date: 2026-09-21

| Family / source | Source failure mode | Scientific consequence | Detectability | Mitigation | Fail-closed rule |
|---|---|---|---|---|---|
| Binance Data Vision archives | ZIP replaced after publication; missing month/day; timestamp unit change; listing/delisting gaps | Silent history mutation or bar-boundary error | High with stored ZIP/checksum/row audit | Preserve bytes and companion checksum at retrieval; hash manifest; schema/unit assertion; gap map | Reject changed checksum or unexplained gap; never redownload over canonical bytes |
| Exchange REST history | Pagination/window limits, delisted-symbol disappearance, mutable endpoints | Truncated or survivor-biased history | Medium | Prefer bulk archive; log every request/cursor; reconcile counts against archive | No complete manifest, no Discovery |
| Official announcement pages | Page edits, inaccessible old pages, publication/effective-time ambiguity | Event-time leakage and wrong population | Medium | Preserve raw page/archive before T0 where required; record publication and effective clocks separately | Missing immutable event identity/time means source gate fails |
| Ethereum archive RPC state | Pruned state, rate limits, provider-specific historical-call behavior | Missing or inconsistent point-in-time state | High with provider quorum | Two-of-three quorum; pin block hash; retry transport only; preserve raw JSON | Quorum failure is technical/provenance failure, never imputation |
| Ethereum logs / SQD | Pagination truncation, reorg/finality handling, omitted empty blocks, schema change | Missing/duplicate events or boundary leakage | High with block-range controls | Bounded requests; advance from last block; canonical identity dedupe; finalized stream; ceiling checks | Reject gaps, reversals, out-of-range rows or unpinned chain identity |
| Xatu public Parquet | Table/schema drift, partition gaps, multiple snapshots per day, current-state substitution | Wrong validator state at predictor time | High after frozen probe | Freeze table/schema; preserve Parquet bytes; pick deterministic epoch window; partition manifest | Four-date probe must pass before full acquisition |
| Hyperliquid requester-pays L2 archive | Envelope/payload clock disagreement; missing hours; authorization/cost boundary | Look-ahead clock error or broken continuity | High with full-corpus diagnostics | Preserve both clocks; quarantine stale rewinds; reset at gaps; separate cost authorization | No normalized clock pass, no validation/outcome calculation |
| Deribit trades/options | Public-history window and strike/DTE sparsity; delisted instruments; quote absence | Execution sample not representative or too small | High with instrument census | Preserve instrument lifecycle; exact trade/quote receipts; no mark/mid substitution | Frozen executable-sample gate must pass |
| CFTC COT | Weekly as-of versus publication-date confusion; revisions | Signal made available before publication | High | Store as-of and release timestamp; enforce information lag; preserve original files | Any observation used before its public-release clock is leakage |
| FRED/ALFRED and macro series | Vintage granularity/loading delay; revised values | Revised-input leakage | High with vintage comparison | Use ALFRED vintage dates; never treat it as release-instant authority | Missing eligible vintage means missing, not reconstructed |
| DeFiLlama/public aggregators | Full-history response crosses protected boundary; adapter/methodology revisions | Protected-data access or retrospective history mutation | Medium | Server-side end date or frozen snapshot required; preserve payload and adapter version | Full-history payload beyond authorized ceiling is blocked |
| BigQuery public chain datasets | Dataset lag, schema/table migration, incomplete program decoding | False absence or protocol coverage error | High with chain/RPC reconciliation | Freeze query text/job metadata; candidate census; raw RPC sample reconciliation | Discovery remains closed until protocol coverage and decoder gate pass |
| Free public RPC | 403/429/5xx, pruning, provider shutdown | Non-reproducible source acquisition | High | Multi-provider transport, bounded retries, local byte cache | Do not change scientific window/threshold to fit transport |
| Commercial/credentialed feeds | No entitlement, opaque vintage, licence limits | Unverifiable or non-reproducible history | High | Require legitimate existing entitlement and export/audit rights | No credentials/purchase/trial; classify blocked or fragile |
| Current token/exchange universe | Survivorship, renamed/delisted symbols, contract migrations | Biased historical population and wrong joins | Medium | Point-in-time universe manifest; contract/address mapping; delisting calendar | Current-survivor backfill is prohibited |
| Cross-venue mapping | Contract multiplier, quote currency, funding clock and symbol mismatch | False spread/lead-lag | High with contract metadata | Freeze venue-specific identifiers and multipliers; reconcile overlapping timestamps | Unresolved mapping conflict stops the candidate |
| Forward/shadow collectors | Downtime, restart gaps, duplicate events, late detection | Selective prospective sample | High with append-only evidence | Idempotency keys, heartbeat, restart receipt, immutable boundary | No backfill represented as prospective evidence |
