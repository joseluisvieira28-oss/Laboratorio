## Scientific archive rule

Negative evidence is never deleted. A failed hypothesis may be revisited only as a genuinely new version with materially changed data, horizon, venue, cost model, signal definition or validation method, and it must explicitly reference the prior failure. Cosmetic rescue or post-outcome tuning is forbidden.
