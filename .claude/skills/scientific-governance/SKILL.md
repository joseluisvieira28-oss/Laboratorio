# Scientific Governance

## Required checks
1. Resolve exact LAB_ID / MVE_ID / candidate identity.
2. Find frozen protocol, amendments, canonical receipts and closeout.
3. Apply Governance V4 without rewriting historical science.
4. Determine separately:
   - scientific verdict;
   - operational lifecycle;
   - mechanism state.
5. Check contamination and protected-data boundaries.
6. Confirm whether outcomes were already opened before any proposed correction.
7. If the mechanism materially changes, require a new identity and zero inherited promotion credit.

## Forbidden shortcuts
- branch name as scientific authority;
- newest file wins;
- BLOCKED => NO_EDGE;
- archive => dead scientifically;
- technical correction after outcome exposure under same ID;
- threshold/cost/horizon/direction/subperiod rescue;
- using protected outcomes to decide whether a successor deserves to exist.

## Output requirement
Any consequential adjudication must state the exact authority branch, commit and path used.
